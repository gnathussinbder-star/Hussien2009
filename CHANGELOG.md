# Changelog

## Phase 1 — Site foundation and learning experience

- Preserved the latest exact user-supplied portrait and logo as standalone JPEG assets without modifying the source bytes.
- Added a 30-question interactive placement test spanning START, A1, A2, B1, B2, and C1 with progress, navigation, scoring, indicative level guidance, category results, and bilingual review of incorrect answers.
- Added an explicit note that the assessment is indicative rather than an official CEFR assessment and does not directly measure speaking/listening.
- Added a YouTube hub for the channel, Shorts, and playlists.
- Added a six-card world photo gallery with fallback cards when external images are unavailable.
- Expanded and refined the FAQ to 15 bilingual questions covering placement, YouTube, the gallery, privacy, learning practice, downloads, and contact.
- Added page metadata, canonical routes, a sitemap entry for the placement test, and a baseline Content Security Policy appropriate to the current static assets.
- Added project rules, security notes, SHA-256 asset checksums, local validation tooling, and a GitHub Actions quality-check workflow.

## Publication status

This ZIP is a review build. It does not modify the live GitHub Pages site. The current GitHub integration denied write operations with HTTP 403, so no branch, commit, or publication was created.
