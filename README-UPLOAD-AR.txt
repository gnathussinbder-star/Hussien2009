حزمة رفع مستقلّة — Hussein Badr English

تحتوي هذه الحزمة على ملفين HTML فقط، وكل ملف يضم تنسيقاته وبرمجته ومحتواه داخله قدر الإمكان:
1) index.html: الصفحة الرئيسية، مع CSS وJavaScript والبيانات وصور الهوية الأصلية مضمّنة.
2) placement-test.html: اختبار تحديد المستوى، مع CSS وJavaScript وصورة الشعار مضمّنة.

طريقة الاستخدام الآمنة:
1. افتح مستودع GitHub وأنشئ فرعًا جديدًا مبنيًا على main، ثم انتقل إلى الفرع الجديد.
2. من Add file اختر Upload files وارفع هذين الملفين إلى جذر المستودع، مع إبقاء الاسمين كما هما.
3. احفظ الرفع على الفرع الجديد فقط، ثم جرّب معاينة GitHub Pages/رابط المعاينة قبل دمج التعديلات في main.
4. لا ترفع ملف ZIP بوصفه الموقع؛ GitHub Pages لا يفك ملفات ZIP تلقائيًا.
5. لا تحذف مجلدات CSS وJS وdata وassets الحالية؛ اتركها نسخة احتياطية.

حالة الاختبار: تم التحقق من مراجع الملفات وصياغة JavaScript والبيانات ضمن فحص ثابت. لم يكتمل اختبار متصفح حي لكامل التفاعلات أو النشر المباشر، لذلك ارفع إلى فرع تجريبي أولًا ولا تستبدل الموقع المنشور مباشرة.

الخطوط والأيقونات وبعض الصور الخارجية تحتاج اتصالًا بالإنترنت. نتيجة اختبار المستوى تقديرية وليست شهادة CEFR رسمية.
