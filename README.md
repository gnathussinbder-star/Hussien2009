# مجلد التنزيلات التعليمية

هذا المجلد مخصص لتنظيم ملفات PDF والملفات التعليمية التي يقرر صاحب المنصة نشرها لاحقًا.

## طريقة إضافة ملف

1. ارفع ملف PDF إلى هذا المجلد داخل مستودع GitHub.
2. استخدم اسمًا واضحًا باللغة الإنجليزية، مثل `english-basics-a1.pdf`، لتقليل مشكلات الروابط.
3. أضف وصف الملف ومستواه وصيغة الاستخدام إلى صفحة الدرس المناسبة.
4. اختبر رابط الملف بعد نشر الموقع، على الهاتف والحاسوب.
5. لا ترفع ملفات محمية بحقوق نشر لا تملك إذنًا بنشرها.

## تنبيه

وجود هذا المجلد لا يعني أنّ هناك ملفات PDF متاحة حاليًا. لا يُعرض رابط تنزيل للطالب حتى يُرفع الملف فعلًا وتُراجع صلاحية نشره.
